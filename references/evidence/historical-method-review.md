# 2010—2020单题考法审阅报告

本轮逐页放大读取本地《2010—2025考研数学一真题（直接打印）》物理页1—43，共11年、253题题干。其中154道选填、44道线代/概率大题及55道高数大题。9份本地独立解析（2010、2012—2019，共81页）的可提取文本用于方法核对，模糊公式回看原图。2011和2020没有本地独立解析，原题已读取、主要方法已分析；本报告不把“已读题干/方法”混同“253题全部独立重做无误”。

可复用索引：historical-item-index.json / historical-item-index.csv，每题均含年份、题号、原文件、物理页、阅读状态、考法与转折。原题PDF与对应解析不是两个独立年度样本。原题的完整文字不另行逐字复制。

## 有证据的结论

### 1. 短题、基础工具与真题感并不冲突

- 2013题1（汇编13页）直接辨认x-arctan x的三阶无穷小；2015题9（22页）ln(cos x)/x²是标准短解；2019题1（36页）x-tan x的阶也如此。
- 2012题8（10页）木棒两段总长固定，相关系数直接为-1；2017题9（30页）偶函数奇阶点导数为零；2020题8（41页）Bernoulli和的CLT标准化也是常规入口。

所以不能根据“能用泰勒”“只需一条定理”“解答两行”一概淘汰题目。应该比较同套卷基础入口的组合、条件辨析与运算层次，而不是强制所有小题都多步化。也不能简单规定只能4道直接题；若采用工作上限，必须与所选近年原卷共同解释。

### 2. 真题概念判断常将关键条件藏在正常数学语言中

- 2020题2（40页）：只给lim f(x)=0，没有给f(0)=0。即便f=o(x²)，也不能据此说在0可导；需要区分点值和去心极限。已自行核对，正确推理是可导且去心极限为0时f(0)=0，进而f(x)/sqrt(|x|)趋0。
- 2012题3（9页）：可微定义的余项阶与两个不同分母，充分性与逆命题由反例区分。
- 2016题4（25页）：阶梯函数在一列点跳跃，但聚集点0仍可能可导；必须回到导数定义并夹逼。
- 2014题6（17页）：对任意k,l的向量无关命题，与原组三向量无关之间是必要非充分。关键词“任意”“一组/三组”“必要/充分”是负担所在。
- 2016题5（25页）：相似关系在转置、逆、多项式下怎样传递；A+A^T不应因分别相似就直接相加。
- 2018题8（33页）：显著性水平改变时接受域/拒绝域嵌套，是检验定义的应用，不必增加复杂检验运算。

设计概念题时，应先写清被考查的逻辑条件、一个支持证明和每个错项的反例/错误条件，再生成选项；不能只往题干加入“独立”“可微”等词算覆盖。

### 3. 极限、积分的灵活性常来自表示转换

- 2010题4（1页）双重求和转为二重积分定义；2017题16（30页）和式转Riemann积分。它们不是提高Taylor阶数。
- 2012题4（9页）比较三个非初等积分，靠符号和周期平移；2018题4（33页）靠奇偶消项和点态不等式。要求硬算原函数反而偏离考查点。
- 2014题3（17页）二重积分选择等价表示，要处理区间拆分和雅可比；2015题4（21页）双曲线扇形域反解极坐标上下限。
- 2018题10（34页）由切线给出的端点函数/导数值计算导数积分；2019题17（38页）面积必须取绝对值、按周期分段后求几何级数。

这些可作为新题结构的参照；不能原题换数字，也不应把它们全部堆到一张模拟卷。

### 4. 线代考法不限于直接给矩阵求谱

- 2011题6（5页）：已知A的基础解系，推断伴随矩阵的基础解系，需要秩、像与核的联系。
- 2013题5（13页）：AB=C且B可逆，比较行/列向量组等价，考线性表示方向。
- 2017题20（31页）：互异特征值给秩下界，已知列相关给上界，再利用列关系写方程通解。
- 2018题21（35页）：初等列变换关系等价于AP=B，参数、列空间、全部解和P可逆相互约束。
- 2020题21（43页）：α不是特征向量使(α,Aα)可逆，由A²α关系恢复基下表示，再判断可对角化。

难度来自信息如何给出及如何转为线代结构，不必强行扩大矩阵阶数或使用Jordan标准形等超纲术语。

### 5. 概率题常先识别随机机制，再计算

- 2011题8（5页）：max与min的乘积恰为XY；若先机械求最大最小分布，会无谓增加计算。
- 2013题22（16页）：连续X经分段截断后，Y含原子质量和连续部分，不能强制写单一连续密度；本题第二问是P(X≤Y)，等号不能随意删掉，因为在Y=X段有正概率。
- 2015题22（24页）：直到第二个超过阈值的观测出现，分布来自停止规则，不是直接给出负二项名称。
- 2016题22（28页）：指示变量与连续X的和，其分布按支持区间分段；“均匀二维分布”不意味着U与X独立。
- 2017题22（32页）：离散+连续随机变量之和，用全概率形成带支持空档的密度。
- 2018题22（35页）：随机符号乘Poisson，零值情形要合并两个来源。
- 2019题22（39页）：随机符号乘指数，分别处理分布、零相关的参数与非独立证明。
- 2020题22（43页）：Bernoulli切换两个标准正态变量；联合分布含对角上的奇异部分，但边缘仍为正态。自行核对得到F(x,y)=1/2 Φ(min(x,y))+1/2 Φ(x)Φ(y)。若习惯性从“联合密度”入手会走错方向。

2010—2020每套原题有两道概率大题；这些单题可以作为方向库，不能把两个题的任务硬塞到新制唯一一道概率大题中。反之，正态方差估计、半正态观测估计、参数支持依赖的均匀MLE也确实在原卷出现，不应一律禁止统计推断题。应与2021—2026方向/负担匹配后选择。

## 建议对skill做的窄而实质的改动

1. 让模拟选填题逐题附“条件作用—考生首次需要识别什么—同型真题这一环节是否仍保留”的命题卡；不要仅列考点名。
2. 将概念题的必要/充分、任意/存在、点值/去心极限、条件依赖、分布类型和事件等号列为审题字段；这比加入更多名词可检验。
3. 允许真题中存在的基础短题；控制重复和整卷组合，删除“所有一行题天然不合格”的倾向。实际难度不靠解答长度判定。
4. 给概率命题卡增加“观测机制/随机变量类型/支持域/是否有原子或奇异部分”，不先假定密度处处存在；统计题核对未知参数、样本信息与支持依赖。
5. 明确大题只在完整推理/计算符合分值与新制总负担时保留，不能用旧年两道概率/两道线代的大题合并制造题量。
6. 每套简评至少给具体题号与一处真实转折对照，明确估时未实测；用户用时偏快应首先检查是否只保留了原题末端运算、是否模板重复，而非直接加深大题。

本轮报告没有真人计时，没有对253题提供完整新解答，因而不能据此宣称已实证解决用户做卷偏快的问题。题干和主要方法的全年度索引已建立，可显著减少后续从头猜测“真题风格”。
