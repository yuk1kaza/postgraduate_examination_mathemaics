# 验收与前向验证

这里区分文件合格、数学正确、考法贴合、真人作答表现四层证据。不得用前一层的通过代替后一层。

## 蓝图必须体现的原题—候选题对照

每题一条记录：

| 项目 | 必须写出的实际内容 |
|---|---|
| 来源 | 年份、题号、原文件、物理页；已读题干/已核验解法/存疑状态 |
| 原题任务 | 考生要从哪些条件推出什么，不能只写考点名 |
| 原题关键判断 | 需识别的性质/隐含关系/反例/分类及方法选择 |
| 候选题任务 | 新题的条件与推理链、实际手算环节和完整答案 |
| 对照变化 | 哪个判断保留，哪个被替换，哪个被删去；替换后是否更直接 |
| 入卷决定 | 保留作基础入口/修订/淘汰及整卷位置理由，不是每题都必须压过原题 |
| 负担依据 | 阅读、探索、运算、写答中负担主要来自哪里；数值估时必须有解释 |

“同为矩阵/概率/积分”只能说明知识归属，不能说明贴合；原题是抽象条件判断而新题是透明矩阵直接读根，必须披露判断被删去。允许基础题，但不能对明显降阶题统一标“中档”掩盖整部分偏易。

## 整卷检查

- 检查10/6/6题数、150分、学科主归属及交叉归属，先与实际参照的学科题数/机会比较，再说大致比例。不要用新增高数选择题挤掉线代/概率选择题后只说“接近60/20/20”。
- 分别检查选择、填空、大题，以及三学科的概念运用/条件判断/结构识别/运算组合。多处模板替换明显降低门槛时，修订这些题，不能只把某道大题变难来补账。
- 单/多问及实际任务数跟随参照和题意；一道充要性证明可能只有一句题干却有两个方向。用户要求的实质证明保留，避免把用户偏好说成每年都有的事实。
- 对照最近已生成卷，检查同一经典反例、同一模板、同一已公开结构的重复；重复多会降低用户探索时间。题目新颖与知识陌生分开，超纲不得作为难度来源。
- 时间预算不能按题型统一填数后凑180分钟。即使总和正确，若选填比参照删去了主要判断，记录“设计证据不足/偏易风险”，先改题。缺首次实测时，只给有说明的相对判断及宽估计，允许“暂不能可靠估分/估时”。

## 数学和来源质量的否决项

题干条件冲突、单选多解/无解、未分清连续与原子概率、分类不穷尽、关键证明缺失、核心计算未推导等，均先修复再交付。原卷转载可能有OCR、排版、答案错误；可疑原题不能不加辨别地当作标准。记录疑点和核对结果，不为坚持“只有一个选项”扭曲定义。

用于推导或程序校验的原题表达式，须先逐项对齐原图：尤其矩阵每行、递推系数、密度的支持域、未知参数及事件等号。程序可以把一个抄错的矩阵算得完全正确，仍不构成对原题的核验。遇到两份核算结果冲突，先回原图查输入，不能凭“脚本通过”或“审阅者人数”裁定；报告保留重要勘误和修正后的验证范围。

## 对技能本身的前向验证

技能有实质改动时，可在临时目录做一次有代表性的出题验证，不必每次修字都重做整卷。任务应是现实请求，如四道选填及线代/概率大题，提供当前技能和最少原始真题，独立执行者不接收预定答案或疑似缺陷。该验证不是用户新套卷，未经要求不覆盖输出，也不能把六题测试称作整卷性能已验证。

检查实际题干、解法、原题锚点和贴合度说明：
- 四个选项是否真的逐一核验，而不是只写正确选项；
- 概念题是否考实际条件推断，还是把术语写进题干；
- 锚点比较是否具体，是否揭示新题删去的判断；
- 概率大题是否因正确且纲内就被误判贴合；
- 选填与大题负担是否各有解释，是否复现统一分钟数；
- 完整解法是否足够从已知重现结果，源题疑点是否诚实处理。

测试范围还要覆盖本次待修缺失，而不是仅挑容易保证正确的常规题。例如用户特别质疑极限/积分的方法识别负担，若试出题仍只有低阶泰勒直接消项，数学正确只能支持“基础入口有效”，不能证明这一专项已经改进。可另试一个有实质表示转换或条件判断的候选，与基础题比较，判断各自合适的位置；不能为测试而把全部基础题强行加难。原始测试和后续修订分别保留，不把局部通过写成整卷或全部问题通过。

对观察到的问题作针对修订；未通过就保留失败结果，不能改写历史称一次通过。通过局部验证后仍需下一套完整卷及用户首次试做来校准时间。最终报告明确本次验证范围和未验证范围。
