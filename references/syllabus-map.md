## 覆盖矩阵

每题记录“主要考点ID + 真正用到的辅助考点ID + 考查层级：理解/运算/综合/证明”。题干提到概念但解题不用，不算覆盖。

| ID | 模块及应检查的内容 | 可以深化的联系 |
|---|---|---|
| H1 | 函数、数列/函数极限、无穷小阶、连续与间断、闭区间性质 | 递推数列的单调有界与极限；分段/抽象函数的连续可导关系 |
| H2 | 一元导数、微分、高阶导数；反函数、隐函数、参数曲线；中值定理、泰勒、洛必达 | 余项阶数与参数消项；导数符号、零点与最值；中值/积分约束证明 |
| H3 | 原函数、定积分/反常积分、换元/分部、变限积分、几何与物理应用 | 对称性和区域；变限函数的导数/极限；反常端点与参数范围 |
| H4 | 向量代数、直线/平面、距离夹角、空间曲线与常见曲面 | 曲面交线、投影与积分域；切平面/法向量与梯度 |
| H5 | 多元极限连续、偏导/全微分、复合与隐函数、方向导数/梯度、极值与条件极值 | 抽象函数条件反求偏导；判别退化点；约束几何与拉格朗日 |
| H6 | 二/三重积分、积分次序、极/柱/球坐标、雅可比与应用 | 非标准区域的拆分、对称和换元；密度/概率几何的自然联系 |
| H7 | 两类曲线/曲面积分，格林、高斯、斯托克斯，路径无关与全微分 | 补线/补面、定向、奇点和区域条件；场的势函数；全微分条件导出微分方程 |
| H8 | 数项级数审敛、绝对/条件收敛、幂级数端点、和函数与展开、傅里叶级数 | 递推系数→幂级数→微分方程；延拓、周期与间断点和函数 |
| H9 | 一阶可分离/齐次/线性等可解方程，可降阶、二阶及常系数线性方程，初值和应用 | 由约束建立方程；初值确定常数；与积分函数/幂级数衔接 |
| L1 | 行列式、矩阵运算/逆/伴随/初等变换/分块/秩 | 参数引起秩变化；矩阵关系→核/像或可逆性→计算 |
| L2 | 线性表示、相关性、极大无关组、基/维数/坐标、正交规范化 | 方程组解结构、参数分类；核/列空间、过渡矩阵（依当年要求） |
| L3 | 特征值/向量、相似与对角化、实对称矩阵 | 重根的特征子空间；矩阵幂和多项式；结构化构造 |
| L4 | 二次型、合同、正交变换、标准/规范形、正定性 | 相似与合同的区别；参数惯性与几何；正定判定与约束 |
| P1 | 事件运算、条件概率、全概率/Bayes、独立与重复试验 | 分层抽样、条件建模；成对独立不推出相互独立 |
| P2 | 离散/连续变量与分布函数、常见分布、变量函数分布 | 分段/非单调变换、原子概率、尾概率与极值 |
| P3 | 二维联合/边缘/条件分布、独立、不相关、二维正态、简单函数分布 | 支持域变化；条件混合；分布函数法/卷积与几何 |
| P4 | 期望、方差、协方差/相关、矩与函数期望 | 相依项交叉矩；非线性函数；零相关与独立辨析 |
| P5 | 切比雪夫、大数定律、中心极限定理及适用条件 | 标准化、抽样均值与概率近似；不可把近似写成精确等式 |
| P6 | 样本/统计量、样本均值方差、正态抽样分布、χ²/t/F与分位数 | 独立性和自由度；统计量构造与分布识别 |
| P7 | 矩估计/最大似然、无偏/有效/相合、区间估计 | 支持依赖参数时的边界极大；估计量矩的存在条件；枢轴量 |
| P8 | 假设检验、两类错误、正态总体参数检验 | 单/双侧拒绝域、显著性和第二类错误；区分假设与真参数 |

H4/H7/H8中的空间、曲面和傅里叶内容，以及P6—P8统计推断容易在过度简化的卷子中消失，应专门核查。不要借“更深”加入测度论、复分析、Jordan标准形、渐近统计理论等超纲必备方法。若需辅助分布/结论，应从纲内知识推导或题中给出，不能默认考生记忆Gamma负阶矩等非常规公式。

## 单卷覆盖和套卷轮换

覆盖地图用于找遗漏，不是强行凑模块数的指标。不再设“高数至少7模块、线代至少3、概率至少4”的硬下限，也不要求每套概率大题都必须统计推断。先尊重2021—2026原卷的学科机会和实际考法，再从地图检查是否不合理地反复只用最基础内容。

同一题只有实质参与解题的知识才计入覆盖；跨考点应自然，不用额外小问硬塞。未覆盖细目记入后续轮换表。用户需要系列全覆盖练习时，规划多套完成，而不是声称22题涵盖全大纲。
