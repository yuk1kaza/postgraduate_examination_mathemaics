# 题目设计：结构、创新与入卷条件

## 从能力设计题，而不是从公式填空

每题先写命题卡：目标能力；主/辅考点；条件作用；入口；关键转折；完整解法；预期错误；手算用时；真题锚点；与原题的结构差异。只有实际参与解题的条件才留下。短题不自动淘汰，长题不自动合格。

- 基础入口：保留参照卷中合理的基础计算和短判断，不设置未经真题统计的“一步题最多4道”上限。检查的是整卷重复与降阶，而非以解答行数判难度。
- 中档：至少有一次方法选择、条件辨别、区域/参数转换或结构识别，不能通过看到题干关键词就直接套唯一公式完成。
- 综合/较难：两到三个自然衔接的知识环节，至少一次确有作用的转折；算式可以不长，但应考查为何这样做。
- 多问：首问建立后问使用的关系、分布、结构或引理；后问提高推理要求。把“求特征值、求特征向量、写Q”拆成三问仍可能只是基础正交对角化，不能仅以问数计创新。

## 可选的组合方向（不是每卷照抄模板）

| 结构方向 | 考查的转换 | 应控制的风险 |
|---|---|---|
| 变限积分/抽象关系→导数或方程→初值/极值/零点 | 从条件提取关系，而非直接给待求公式 | 保证可解、正则性充足，不能把换名积分当作求出函数 |
| 递推系数→幂级数→和函数/边界 | 收敛域、逐项运算与方程的联系 | 端点独立核查；不得默认边界逐项操作合法 |
| 场/全微分→兼容条件→常微分方程 | 多元偏导与一元关系的衔接 | 区域连通、可微阶数、常数适用区间 |
| 重积分区域→次序/坐标选择→分段计算 | 判断几何和计算成本 | 全部边界与雅可比一致，不堆难积函数 |
| 开曲线/开曲面→补线补面→积分定理 | 定向、补偿、对称消项 | 奇点、外法向和补面符号，避免一眼全抵消的空壳 |
| 参数矩阵→秩/解空间→分解或矩阵幂 | 结构代数与参数分类 | 避免全为对角/已分块矩阵；完整覆盖临界参数 |
| 二次型→谱/惯性→参数或约束 | 不同等价关系和几何的联系 | 相似、合同、正交相似不得混用 |
| 机制/条件分布→联合/边缘→数字特征 | 建模、支持域、相依性 | 不能把“相关=0”误写独立，避免非纲内技巧 |
| 样本信息→似然/矩估计→无偏性/区间/检验 | 统计建模及参数解释 | 指数分布率/均值参数统一；支持依赖参数时检查边界 |

## 证明题的实质要求

证明不能只把给定等式代入另一等式。先确定要证明的结论，再确认条件确实足够、存在性不是数值巧合。

可设计：构造辅助函数并用Rolle/中值定理；从积分约束推出零点或导数结论；单调/凸性与积分不等式；递推数列或级数性质；矩阵结构命题。默认至少一道高数大题的主要分值用于证明；证明小问至少需要一个不能直接抄题干得到的引理/构造/定理选择。存在量词、严格不等式、端点、充分必要两方向都必须检查。

## 创新检查与原创边界

创新体现在提供信息的方式、需要识别的关系、条件与结论的交换、参数临界情形、问题间的递进或自然建模。与所选锚点比较条件组织、方法判断和运算负担。原创不要求每题都发明新解法：可保留常规考法与基础题；仅换数字、坐标名、函数名、背景名或打乱选项不足以把原题标为原创。不得为了每题“创新”而令整卷偏离常见真题风格。常规结构可以使用，不为追新引入超纲工具，也不声称做过全网查重。

选择题的三个干扰项应对应不同且合理的错误路径（如忽略端点、遗漏雅可比、混淆必要充分、把不相关当独立），各自实际算出，避免凑数和重复值。不能为了打散答案字母改错结论，也不因答案序列碰巧相同重写合格数学内容。

## 淘汰条件

候选题出现以下任一情况，先修订/替换：12分大题只需常见公式一步代入；大段条件对解题没有作用；多问互不相关；核心做法与真题只差数字；没有可用纲内解法；结果无合理闭式却没有允许的表达方式；通过删去难步骤伪造短解；计算量明显不适配分值。一般参数积分无初等原函数时，先设计可求的特例/关系，不用特殊函数给题目补洞。

选填的条件判断、线代/概率考法、极限/积分的套路重复及分部分压力，另按 [authenticity-and-feedback.md](authenticity-and-feedback.md) 审核。

## 概念与概率任务的隐含条件

概念题应具体写出量词、点值与去心条件、必要/充分方向及每个错项的理由。概率题先明确随机机制、变量类型与支持域；变换后可能有原子或奇异部分，不能先假定一定存在联合密度。2013-22的P(X≤Y)不能因X连续就删去等号：Y由X构成，事件X=Y可有正概率。2020-22的切换模型亦有对角奇异部分。新制唯一一道概率大题不能拼接旧年两道大题来追求多考点。

评估计算量要考虑清楚可行的纲内短路线，而不是命题者刻意选择的长路线。若候选题通过直接参数化比补线定理简单得多，实际方法选择与负担要据此重新描述，不保留原长路线的分钟数。
