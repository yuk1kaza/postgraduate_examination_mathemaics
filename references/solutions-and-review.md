# 详解深度与数学审校

## 按2013解析样例写作

实际打开用户指定的 `examples/2013数学一解析.pdf` 的基础题、综合题和方法点评页，比较展开层次；不能只引用文件名而不阅读。每题完整交代：思路为什么选这个方法；定理条件；从已知开始的中间推导；最后结论。常考点附可迁移的知识总结，代表性题给出方法比较。允许解析远长于试题，不设置人为页数上限。

- 极限/泰勒：写明展开阶数、余项、复合变量的量级、消去项和不适用直接等价替换的位置。
- 求导/极值：列出链式关系、定义域、临界点、符号/判别；退化时重新分析。
- 积分：说明区域和换元理由，写清边界、拆分、雅可比、原函数/分部步骤和端点代入。不能从一个长积分直接跳答案。
- 级数：写判别过程、收敛半径、两端点及逐项运算条件，不假定所有熟悉级数的和都可无证明引用。
- 微分方程：写分类或转化、特征/辅助方程、特解选择、常数确定及代回检验。
- 线代：列增广矩阵/行变换、秩与参数分类；特征子空间的求法、重根正交化/单位化及变换结果复核。
- 概率统计：分段支持域、事件转换、密度/分布函数和归一化；逐步算矩；似然定义域、边界及极值；有偏量写出偏差表达式与矩存在条件。
- 证明：先解释构造动机，再逐步核对定理条件，写明量词、端点、必要/充分两方向和等号条件。例子、画图或数值试验不能替代证明。

大题每小问给建议评分点，分值加总等于题分；这是模拟评分建议，不冒充官方细则。小题干扰项分析应解释真实错误来源，不必重复四遍同一运算。

知识点总结至少包括“本题用到的一般结论/套路 + 适用条件 + 一处易错点”，需要时给简短推导；不贴与本题无关的百科，也不让总结代替解答。

## 解答题完整过程标准

解答题（默认17—22题）必须逐题逐问给出至少一种完整可复核的解法。单问题内没有编号的多个要求，也须逐项作答。详解的标准是读者能沿正文重现结果，无需自行补做主要计算或证明；不要求把每次简单加减都拆成一行，也不要求所有题都写第二种方法。

### 一条完整解法应包含什么

1. 说明已知条件、所求量、变量定义与必要的定义域，明确为何采用该方法。
2. 写出建模、辅助函数、坐标变换、方程或积分的建立过程，交代理由和使用定理所需的条件。
3. 给出主要计算的中间状态和连续等式链，包括参数、系数、常数、积分值、解向量等怎样实际求出。
4. 对分段、分类、临界参数、端点、等号及存在条件分别处理；后问引用前问时写出所用结论及代入过程。
5. 收束到题目要求的每一项结果；按需代回检验，随后附评分建议、方法点评和知识总结。

“经计算得”“化简可得”“解方程即得”“同理可得”不能代替决定结果的运算。确为完全重复的步骤可引用已经展示的式子，但要给出本次参数、范围和结论。证明不能只列定理名称、辅助函数名称或结论；每次定理应用都要写明条件、区间和推出的关系。

### 各类题必须展示的实际步骤

| 题目类型 | 不能省略的过程 |
|---|---|
| 极限/展开 | 所需各项展开、复合量替换、消项、余项阶数、约分后取极限；不能仅写“展开到三阶即得” |
| 积分/积分应用 | 从区域约束推出上下限/拆分点；换元微分与雅可比；被积式变形、原函数或分部积分、各段端点代入和合并。积分定理题还须算补线/补面项与方向符号 |
| 微分方程 | 方程转化、齐次解与特解的求法；初始条件组成的代数方程及常数求解；回到原变量并检验 |
| 级数 | 审敛的比值/根值/比较计算、端点；和函数的变换/积分/求导过程、常数确定与有效区间 |
| 矩阵/方程组/二次型 | 展示决定秩和解的关键初等变换（标注行操作及中间矩阵）；行列式/特征多项式的变形；每个特征子空间的求解；必要的正交化与单位化。不能直接从原矩阵跳到特征向量或Q |
| 概率分布与数字特征 | 事件和支持域转换、分段界限、密度/分布函数推导；归一化、边缘/条件密度及各矩的实际求和/积分；整理最终分段形式 |
| 参数估计/区间/检验 | 从样本及支持写似然/统计量，展示求极值或构造枢轴量的过程；所用分布/矩的依据；代入参数、期望方差、分位数/拒绝域的具体计算和适用条件 |
| 证明/存在性/不等式 | 构造动机，连续/可导等条件，定理应用的区间及点的范围；各个方向、严格性或等号条件，最后回到原命题闭合论证 |

例如积分已变为 $\int_0^1u\ln(1+u)\,du$ 时，不能直接写“分部积分得1/4”。应实际展示：

$$
\begin{aligned}
I&=\left[\frac{u^2}{2}\ln(1+u)\right]_0^1-\frac12\int_0^1\frac{u^2}{1+u}\,du\\
 &=\frac12\ln2-\frac12\int_0^1\left(u-1+\frac1{1+u}\right)du\\
 &=\frac12\ln2-\frac12\left[\frac{u^2}{2}-u+\ln(1+u)\right]_0^1=\frac14.
\end{aligned}
$$

这个例子说明关键运算的展开程度，不是要求所有题使用同一写作模板或以行数衡量完整性。

### 排版前做过程完整性检查

逐项对照题干的所有要求，检查每个最终结果能否沿正文追溯到已知条件。遇到突然出现的常数、矩阵、积分值、密度或存在性结论，补写求解过程。先写完整正文，再附评分点；只有评分提纲、证明框架或最终答案的题不算详解完成。

用符号/数值工具独立验算后，仍须把可由考生理解的数学推导写入解析；工具输出不能作为缺失步骤的替代品。解析PDF编译后再次检查公式是否完整保留，不能为页数、输出长度或分页方便删步骤。篇幅较长时允许拆源文件或分阶段写入同一份完整解析PDF，而不是用“其余同理”“略”结束。

## 两轮审校

第一轮以做题者身份从题干重新解答，尽量不沿用命题时的路线。第二轮站在整卷层面审查分布、重复、分问、证明和时间。把发现、修正和最终验证写在 `命题与审校记录.md`；不要把勾选“已检查”当证据。

1. 每题核实条件相容、定义域、可解性和结论；参数题检查临界值与特殊值，统计题检查样本量条件。
2. 单选对四个选项分别代验或证明真假。填空核实唯一性及等价表达；概率量在[0,1]且密度归一，方差非负。
3. 综合计算题和高风险中间式，至少一种独立核验：另一种积分次序、坐标或方法；代回方程；矩阵乘法/迹/行列式；从分布函数重算；用SymPy/数值积分做交叉核验。工具结果只能辅助审校，不能替代可供考生阅读的解析。数值吻合不证明普遍命题。
4. 证明题先检索反例（常数/线性函数、端点、极端参数等），再检查推理链。找不到反例不等于证明成立。
5. 对多问题检查小问共享与递进是否自然，首问是否直接泄露后问；对单问题检查任务完整性，不能因其没有分问判为浅题。比较隐含任务数、证明双方向、参数分类等实际负担；建议分值与推理/计算成本是否相称。
6. 按 [time-and-workload.md](time-and-workload.md) 从最终解法估计阅读、探索、运算、作答和检查用时，并合计22题、各部分及全卷；计算量不能仅用解答行数计。若全卷一小时即可套公式完成，返工增加结构性判断；若依赖长展开或超纲技巧才能180分钟内完成，返工控制负担。

## 审校记录的最小字段

- 资料证据：目标考试年度、查阅日期、官方/转载/本地性质、URL或路径、页码、已读范围、缺失内容。
- 22题蓝图表：题号、分值、学科主归属、主/辅考点ID、题型/显式分问数/实际作答任务数、证明任务、核心转折、真题锚点、结构变化、估计时间。
- 汇总：150分与题型校核；学科分值；覆盖/未覆盖与轮换；单问/多问题组合与所选真题的对应依据、一道实质高数证明；全卷预计基本完成时间、检查时间及总预算。
- 过程完整性：解答题各问/各项要求对应的正文位置，发现的跳步及补全情况；
- 实际审校：问题及修正；高风险题的独立结果与工具/方法；PDF编译和预览结果；未解决限制。

“难度评分”“原创性评分”是设计自评，不能用漂亮表格掩盖题目浅、答案错或缺乏真题证据。任何硬性结构不满足或数学错误未修复，不把整卷称为完成。

## 贴合度复核

按 [authenticity-and-feedback.md](authenticity-and-feedback.md) 单独审查选填、高数/线代/概率和极限/积分结构；审校记录增加真题锚点、相对难易/灵活度/复杂度/计算量及依据、最近套卷重复结构、用户实测与不确定性。每次给用户简评，不能只把依据留在内部记录。
