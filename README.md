# 考研数学一模拟卷生成 Skill

为 Codex 提供有真题依据的数学一原创命题流程：设计模拟卷、给出完整解答，并分别输出试题 PDF 与解析 PDF。技能名称：`kaoyan-math-mock-generator`。

## 能力与命题依据

- 单题的考法、条件判断和方法选择参考本地 2010—2026 年真题；整卷题型、学科布局及任务组合以 2021—2026 年为参照。
- 近六套原卷按主要解法归属，选择题为高数/线代/概率 4/3/3，填空为 4/1/1，大题为 4/1/1。默认满分 150 分，考试时间 180 分钟；单问、多问组合根据实际参照安排。
- 选择、填空、大题分别审校，关注定义应用、条件辨析、计算量和探索负担；至少一道实质高数证明是本技能的定制要求，不代表每年原卷都如此。
- 每道解答题的各项任务均提供完整推导与中间算式，附必要的方法点评、知识总结和建议评分点。
- 每套给出难易、灵活度、复杂度、计算量和估时依据的简评；原题与候选题的对照记录可追溯。

## 安装

需要 Git 和支持本地技能的 Codex。将本仓库克隆为个人技能目录中的同名文件夹。在 Windows PowerShell 中运行：

```powershell
git clone https://github.com/yuk1kaza/postgraduate_examination_mathemaics.git "$env:USERPROFILE\.codex\skills\kaoyan-math-mock-generator"
```

若目标目录已存在，请先保留自己的修改，再将仓库克隆到其他位置进行比较，避免覆盖。其他系统可将仓库放到 `~/.codex/skills/kaoyan-math-mock-generator`。技能目录内应直接包含 `SKILL.md`，不要再多套一层文件夹。

## 使用

在 Codex 中明确调用技能，并提供资料目录和输出目录：

```text
$kaoyan-math-mock-generator

请参考本技能 examples 中的数学一真题生成一套原创模拟卷。
单题考法参考全部年份，整卷设计参考2021—2026年。
请先完成命题蓝图和原题对照，再独立验算。
输出试题PDF、完整详细解析PDF、可编译源文件及命题审校记录，
并说明整卷与选填、大题各自的难度和预计作答负担。
将结果保存到新的 output 子目录，不覆盖旧卷。
```

也可指定专题或题数。专题训练可缩减整卷结构要求，仍需保证条件严谨、答案正确与推导完整。生成后反馈选填、大题用时、得分、错题和对照真题年份，有助于继续校准。

## 文件结构

```text
SKILL.md                  技能入口与执行流程
agents/openai.yaml        名称及默认调用提示
references/               命题、范围、详解、排版及验收规范
references/evidence/      385题索引、原PDF指纹及方法审阅记录
scripts/check_evidence.py 来源、题号覆盖、页码与分值校验
examples/                 配套真题与解析PDF
```

`output/`、`review-*/`、临时图片、OCR文本及LaTeX编译缓存不纳入Git。仓库保留可复用技能、参考PDF与整理后的证据资料。

## 校验与运行环境

来源校验仅需 Python 3 标准库，在仓库根目录执行：

```powershell
python -X utf8 scripts/check_evidence.py --examples examples
```

脚本检查14份PDF的SHA256、385题编号覆盖、页码边界及近期六套分值。更换原PDF后需重新核对并更新相应索引和指纹，不能仅改指纹以消除报错。

PDF内容读取需要可用的文本提取或页面/OCR工具；扫描件必须回看原图。排版可使用支持中文的LaTeX与XeLaTeX，或Codex中可用的等效工具。实际交付须包含可打开的两份PDF，预览或编译日志不能代替导出的文件。

修改技能时，可使用 Codex `skill-creator` 附带的 `quick_validate.py` 检查技能格式；此工具不属于本仓库依赖。

## 验证范围与限制

现有索引覆盖17年、385道原题题干。索引区分阅读、方法分析和独立验算，不能理解为全部385题均已重新证明正确。方法核对记录见 [近期审阅](references/evidence/recent-method-review.md) 和 [历史审阅](references/evidence/historical-method-review.md)。

技能曾接受六题及一道补充积分候选的局部出题/独立复核；这不能替代完整150分卷的审题、PDF核验和真人首次作答。题目短、使用泰勒或解法简洁不必然代表过易；难度判断应比较原题中的关键判断与整卷组合。

参考PDF包含转载/解析资料，可能有排印、OCR或所附答案错误；遇到疑点应核原图和严格数学推导。当前年度大纲以官方原文为准，未读取全文时应明确说明。

## 版本维护

修改后先校验证据完整性、参考链接及技能格式，再记录有意义的提交。涉及命题规则的实质修改，还应进行针对性出题验证，保留实际观察和限制，避免只改预计用时或难度标签。个人练习结果可保存在忽略的 `output/` 中；提交前用 `git status` 和 `git diff --staged` 检查范围。
